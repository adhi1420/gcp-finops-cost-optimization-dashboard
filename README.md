# Google Cloud FinOps Cost Optimization Dashboard

## Objective
Analyze Google Cloud spending data to identify waste and cost-saving opportunities.

## Tools Used
- Microsoft Excel
- Pivot Tables
- KPI Dashboard
- Data Cleaning

## Key Insights
- 371 underutilized resources identified
- 373 high-cost resources flagged
- Avg CPU utilization: 50.94%
- Top spend concentrated in Cloud CDN, Cloud Build, Pub/Sub

## Recommendations
- Rightsize low-usage resources
- Improve tagging governance
- Set budget alerts
- Review high-cost services

## Files Included
- Excel workbook
- Dashboard screenshots

## Outcome
Built an analyst-ready FinOps reporting dashboard.
